# Release Gates
P0 blockers: crash, deterministic mismatch, broken objective, missing controls/spawn, lineage drift, public version regeneration, moderation block, secret exposure.
Targets: >=95% corpus reaches playable proxy; p50 <12s/p90 <25s; >=90% initial golden prompts compile without full regeneration.
Runtime: 100% deterministic corpus replay equality; server budgets enforce entity/rule growth.
Product: anonymous share play; parent immutable after remix; post-run replay/remix works; technical UI unnecessary.
Ops: permanent backend, health endpoint, external uptime monitor, rate/spend caps, provider degradation, exact submitted commit/deployment pinned.
