# WORLDSTREAM — Reality Compiler pilot

**Focus kategorie:** procedural worlds

Registration is not verified.

A short source becomes a discrete spatial scenario with executable rules and source evidence. A visitor must physically reach two stations before a timer expires. The user changes the timer and compares the same recorded actions in two branches: an unlocked object in the original and an alarm in the intervention.

The model proposes declarative simulation data. A deterministic runtime executes movement, rules and replay; the model does not execute generated code. The source panel retains original source bytes, references, assumptions and review status. Why? connects an executed rule to its evidence. A structurally valid citation is not a semantic guarantee.

The current demonstration runs locally in a controlled Chromium window through the author's existing Codex subscription using the official CLI in WSL2. There is no API fallback. The historical subscription series recorded a creation median of 126.22 seconds and p95 of 180.43 seconds, missing the original 30/60-second targets; edit p95 was 3.73 seconds. These observations predate the new human parameter-review flow. CLI timings include process and transport overhead. The historical benchmark retains every attempted or unattempted pair and its failures; a new live before/after measurement remains pending.

The accepted scope is short explicit text, discrete spatial procedures and one timer intervention per project. Original text and a separate optional supplement each accept up to 4,000 Unicode code points, with a combined 16,000-byte UTF-8 limit. Before acceptance the user reviews seven critical parameter groups; missing or conflicting support blocks acceptance. This acknowledgement does not certify semantic correctness. Geometry is schematic. Source projects can be explicitly saved in this browser and restored through validated replay of both branches; ordinary server sessions expire on restart. Arbitrary documents, URL/PDF ingestion, physical accuracy and universal prompt support are not established.

Five-person usability evidence and independent semantic review remain separate requirements. This local handoff is not a completed public competition submission: hosted URLs, final video, operational availability and author eligibility/registration are pending. Instructions and precise status are in README.md and evals/reality-compiler/submission-readiness.md.

One archived successful development run recorded a CLI generation call of 93611 ms (93.611 s). This includes local transport and CLI overhead; it does not measure provider compute time alone.
