# WORLDSTREAM — Reality Compiler pilot

**Focus kategorie:** procedural worlds

Registration is not verified.

A short source becomes a discrete spatial scenario with executable rules and source evidence. A visitor must physically reach two stations before a timer expires. The user changes the timer and compares the same recorded actions in two branches: an unlocked object in the original and an alarm in the intervention.

The model proposes declarative simulation data. A deterministic runtime executes movement, rules and replay; the model does not execute generated code. The source panel retains original source bytes, references, assumptions and review status. Why? connects an executed rule to its evidence. A structurally valid citation is not a semantic guarantee.

The current demonstration runs locally in a controlled Chromium window through the author's existing Codex subscription using the official CLI in WSL2. There is no API fallback. Two successful development generations took 85.5 and 93.6 seconds for the model call alone; these observations are not a p95. The browser then verified different outcomes after a timer intervention. See the current subscription benchmark for the separate locked holdout and every attempted or unattempted pair.

The accepted scope is short text up to 2,000 characters, discrete spatial procedures and one timer intervention per project. Geometry is schematic; the project lives in the browser tab. Arbitrary documents, URL/PDF ingestion, physical accuracy and universal prompt support are not established. Missing conditions can require clarification and unsupported proposals can be rejected.

Five-person usability evidence and independent semantic review remain separate requirements. This local handoff is not a completed public competition submission: hosted URLs, final video, operational availability and author eligibility/registration are pending. Instructions and precise status are in README.md and evals/reality-compiler/submission-readiness.md.

One archived successful development run recorded a CLI generation call of 93611 ms (93.611 s). This includes local transport and CLI overhead; it does not measure provider compute time alone.
