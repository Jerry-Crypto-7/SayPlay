# 11 · Voice & UI copy

Short. Plain verbs. Second person. A little cheeky when you win, calm and useful when something breaks. Sentence case. Max one joke per screen.

## Say this, not that
| Say | Not |
|---|---|
| Make it! | Generate / Submit / Create game |
| Say it in one sentence | Enter your prompt |
| Surprise me | Random prompt |
| Reading your idea → Building the world → Setting the rules → Painting it in | Designing the challenge / Building a playable version |
| Quick version · the full-detail one is on its way | The AI is busy right now – you are playing the quick version |
| Change one thing | Edit prompt parameters |
| You did it! / So close. | You won / Game over |
| Dare a friend to beat it | Challenge a friend / Share to social media |
| Remix it | Change it |
| Link copied. Go dare someone. | Copied to clipboard |

## Glossary (use the same word everywhere)
- **game** (not world, level, experience) for the thing you play.
- **idea** for the sentence. **Make** for creating. **Remix** for changing someone's game or your own.
- **Dare** for sending a game with your score to beat.

## Errors
State what happened + what to do. No "Oops", no apologies, no emoji.
- Too vague: "Add who you are and what you're doing, like "a cat stealing fish"."
- Blocked content: "We can't make that one. Try a different idea."
- Build failed: "Couldn't build that. Try fewer rules." + **Try again**
- Offline: "You're offline. Your idea is saved — we'll build it when you're back."

## Game text (generated)
Objective lines are imperative, ≤ 50 chars: "Grab the eggs, then run for the gate!" World tags ≤ 12 chars: "Dog! Run!", "Gate", "Hot!". Enemies are named by what they are ("dog", not "s dog" — validate generated labels).
