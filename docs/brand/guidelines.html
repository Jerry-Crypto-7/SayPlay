02

Six rules that make it Sayplay

If a screen breaks one of these, it stops looking like Sayplay and starts looking like a template.

1

Ink outlines everything

Every interactive surface has a 2.5px ink border. It keeps the UI readable on top of any generated 3D world.

2

Shadows are hard, never blurred

Depth comes from a solid ink offset (3, 5 or 7px). No blur, no opacity, no gradients.

3

Pressing sinks the button

On press, a button moves into its own shadow. This is the core tactile moment of the brand.

4

Tilt is a treat

Only idea cards, world tags and celebration badges may rotate, by 1.5 to 6 degrees. Buttons, inputs and text never tilt.

5

One loud colour per screen

Tomato is reserved for the single primary action. Sun supports it. Everything else is cream, paper and ink.

6

Plain, cheeky words

Short sentences, real verbs, a little attitude. The UI never apologises and never sounds like a robot.

Clear space & size

Keep clear space of at least half the mark's height on every side. Minimum lockup height: 24px on screen. Below 24px, use the mark alone (min. 16px).

Never

Retype the wordmark in a font (use the SVG, it is outlined). Recolour the bubble anything other than tomato. Add shadows, gradients or rotation to the logo. Place the full-colour logo on tomato or photos.

Quick version

HUD rules

  • HUD surfaces are always opaque paper or sun with an ink border. Never glass, blur or transparency: generated worlds can be any colour.
  • Top-left: progress (what to collect). Top-right: time and pause. Bottom: restart, remix, share. Nothing in the middle third.
  • Progress is shown as the actual objects (eggs), filled vs. dashed, plus a count.
  • World tags follow a 3D object (screen-projected every frame, clamped 16px inside the safe area). Tomato = threat, sun = goal. Max 3 visible.
  • Generation state lives in a small status pill, never a blocking dialog.
  • Minimum 50px hit area for every HUD control. Respect safe-area insets.
  • Objective line appears for 4s at start, then collapses into the progress pill.

Mobile (0–599px)

+--------------------------+
| appbar 62                |  20px side margin
|                          |
| headline (display-l)     |  24px between groups
| [ prompt bubble ]        |
| [ primary button 62 ]    |
| idea grid 2 cols, gap 12 |
|                          |
| ( tab bar 66, float 12 ) |  + safe-area bottom
+--------------------------+

Tablet (600–1023px)

Same single column, max content width 560px, centred. Idea grid goes to 3 columns.

Desktop (1024px+)

+-------+------------------------------+
| side  | headline (display-l 56)      |
| nav   |                              |
| 240   | [prompt bubble ]  [ live ]   |
|       | [max 640       ]  [ game ]   |
| logo  | [ Make it! ]      [ 16:9 ]   |
| Make  |                              |
| Play  | idea grid 4 cols             |
| Mine  |                              |
+-------+------------------------------+
  • Tab bar becomes a 240px left rail with the same items and active style.
  • Content max width 1200px, 12-column grid, 24px gutters, 48px outer margin.
  • Game plays in a 16:9 stage (max 1280×720), HUD scales with the stage, not the window.
  • Keyboard: Enter submits prompt, Space pauses, R restarts, Esc closes sheets. Hover = shadow grows sm→md, press still sinks.
