# Fixed stock CONNECT local refusal (UNINTEGRATED)

`create_refusal_session(parent_deadline)` creates one owned nonblocking IPv4 listener at `127.0.0.1:0`. It returns a single-use session with `ownership.address`; `run(cancel, observer=None)` accepts at most one connection. `cancel` is an optional trusted `threading.Event`. `close()` is idempotent, including before `run()`. Import and direct entry do not launch CLI or create sockets; direct entry refuses integration. The setup plus negotiation deadline is two seconds from factory entry, clamped to the caller's finite monotonic parent deadline. It is not reset after accept.

The only accepted request is exact HTTP/1.1 CONNECT for `api.openai.com:443`, Host with that same authority, and `Proxy-Connection: Keep-Alive`. This is a separately selected no-auth stock-provider shape. It does not accept the prior `fixture.invalid` authored request, ChatGPT-auth provider authority, header variants, credentials, bodies or early TLS bytes. A valid request receives only a fixed local HTTP 403 with zero content and close. No HTTP 200, upstream socket, target DNS, TLS handling, provider endpoint rewrite, account operation or model turn exists here. The proxy URL is not automatically installed in any CLI environment.

These are source-derived expectations, not evidence that a current stock CLI emitted this request. The existing metadata startup prewarm trigger is described in `scratch/session8-actual-cli-proxy-next.md`; allowing a successful tunnel could permit subsequent warmup payload, so this helper always refuses before TLS.

The report retains all actually observed request bytes as a base64 raw transcript **only when exactly equal to the safe fixed request**. Rejected input has byte count and SHA-256, with raw omitted; unknown or credential-bearing headers are never copied into reports. Observed early data is refused. Closing the connection after refusal cannot establish absence of bytes arriving later. Actual partial refusal writes remain counted on failure. Deadlines and cancellation are checked after selector return and after I/O, including before success. Selector construction is inside the owned cleanup region. Any unknown close outcome sets a process-wide no-next-session fence.

Accepted tuples and socket identity are observation metadata, **not CLI provenance**. `cliProvenanceValidated` and `productionReady` remain false. The optional trusted seam is `observer(phase, observation) -> dict`. Its two phases are exactly `accepted-before-read` and `header-complete-before-refusal`; observation contains only copied `peer`, `local` tuples and accepted `socket` identity. Each actual returned record is JSON copied and capped at 16 KiB; booleans are rejected. Records are retained as `provenanceObservations`, without validating their claims or setting provenance credit. Observer exceptions, malformed records and exhausted deadlines close before refusal. The source-bound observer must itself use bounded metadata operations: a synchronous Python callback cannot be forcibly interrupted by this core. There is currently no built-in trusted PID/pidfd observer implementation. The next bounded composition must pin the actual owned CLI generation and network namespace, map the exact client tuple through its own network namespace TCP table to a unique socket inode, and observe that inode in the pinned CLI's FD metadata before and after the request. Even that is a sequence of observations of a socket holder, not atomic byte authorship or a general FD-sharing defense. It must not open CLI target descriptors or inspect environment/credential contents. This listener does not spawn a CLI, validate namespace confinement, or impose a process resource envelope.

Tests are deterministic mocked sockets/selectors only. They exercise fragmentation, partial refusal writes, early data, credential-safe evidence omission, deadline after select/write, cancellation under backpressure, setup/selector failure cleanup, unknown-cleanup fence and single-use lifecycle. No runtime network, CLI, authentication or kernel validation credit is claimed.
