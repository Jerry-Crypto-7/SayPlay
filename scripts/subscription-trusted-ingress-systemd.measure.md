# Trusted ingress inside the resource unit

This dedicated measurement composes the source-bound basic supervisor loop,
resource validator and full ingress child validator. It invokes only the fixed
relay selector `--trusted-ingress-boundary`; no caller arguments are accepted.
The first actual run passed after source review and the archived source freeze;
see the evidence below.

The exact 30-file inventory comprises the basic ingress inventory of 24 plus
this wrapper, the resource measurement, relay, resource probe, receiver and
rendezvous controller. The actual controller's separate six-source map and
ready/start ten-helper map must match the same frozen bytes. Before/after/current
hashes and loaded measurement modules are bound independently.

The actual wire must contain, in order, systemd ownership, ingress ownership,
ingress handoff, ready, started, child output, capsule terminal, and ingress
terminal. No basic launcher ownership or terminal is fabricated. In particular,
the original five-field startup packet and raw child response remain unchanged.
The child replay receives the externally observed socket and nonce directly.

Before start, admission checks the unit UUID, controller PID, fixed rendezvous
path, six-source map, exact receiver ACK, socket identity after pivot, typed
runtime facts, pinned CLI/bwrap and ten helper hashes. The resource validator
checks private-manager identity, unit process generation, and 2 GiB memory,
zero swap and 64 tasks. The terminal must preserve that identity and confirm
the same pre-start readback and removal of the owned unit and leaf.

The separate ingress terminal must confirm owned socket/directory removal,
closed peers and threads, stable sources, EOF and exact BEFORE/AFTER/ACK byte
accounting. It retains `remoteUnitCleanup: NOT_ATTESTED`; the resource and capsule
receipts supply their own cleanup evidence. Raw child replay independently
validates the protected HOME/control/socket boundary while the actual app-server
is alive. This is the authored credential-free route, not authentication,
provider inference, aggregate exhaustion or a new cgroup escape sweep.

Existing 180/200/5/220-second job/command/grace/guardian contracts, five-second
handoff/broker budget and 22/30-second child budgets are unchanged. Every attempt
uses unique scratch receipts and candidate wire. Failed and incomplete records
remain failures; there is no automatic retry.

Offline tests exercise full independently authored replay and negative owner,
ACK, generation, resource, raw child, source, ordering and cleanup cases. The
first run's 21-pass/1-fail nonce test used the fixture's existing nonce; it is
preserved as a test-authoring error, with no runtime evidence relabelled.
